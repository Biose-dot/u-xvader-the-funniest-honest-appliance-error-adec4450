One line, at most 200 characters: the funniest honest error message an
appliance could show — for the make.fun competition
[`u-xvader-the-funniest-honest-appliance-error-adec4450`](https://make.fun/bounty/u-xvader-the-funniest-honest-appliance-error-adec4450)
([competition page](https://make.fun/c/u-xvader-the-funniest-honest-appliance-error-adec4450)).

## The entry

> ERROR UE: Drum unbalanced. One sock has unionized with the duvet cover and is holding the spin cycle hostage. Redistribute the laundry to resume.

The joke is the fault itself, not a pun bolted on: an unbalanced drum
is a real washing-machine error (UE), and anyone who has opened a
washer mid-cycle knows exactly how one sock ends up welded to the
duvet cover, strangling the spin. The machine states the problem
deadpan, names the hostage-taker, and — like every honest appliance —
blames you, politely, for the fix.

## Running

```sh
python3 main.py   # writes entry.txt to $MAKEFUN_OUTPUT_DIR (default /output)
```

`main.py` is pure Python 3 stdlib: it reads the committed `entry.txt`,
writes it to the output directory, and prints it. No network, no
randomness, fully deterministic.
